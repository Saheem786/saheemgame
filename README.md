# saheemgame

Unreal Engine game project (Engine Association: 5.8).

## Open the project

Open `saheemgame.uproject` in Unreal Engine 5.8. Project assets and configuration are stored in `Content/` and `Config/`.

Generated editor/build data (`Binaries`, `DerivedDataCache`, `Intermediate`, and `Saved`) is excluded from version control.
